Implement a simplified CPAchecker (Configurable Software Verification) framework in Python. Starting from a skeleton with CFA data structures, CPA interfaces, a C parser, and benchmark programs, progressively build: (1) the CPA worklist algorithm with value analysis, (2) predicate analysis with path feasibility checking, and (3) k-induction and bounded model checking. Each stage must correctly verify 4 benchmark C programs (12 total).
